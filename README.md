# 經管團隊（中壢業務中心）

中壢業務中心經管團隊各組負責人使用的工作 App。手機、平板、Windows、Mac 的瀏覽器都能用，也能「安裝」成 App，第一次開啟後沒有網路也能用。

網址：https://brucehu43.github.io/gongsheng-mgmt/

## 功能

| 組別 | 功能 |
|---|---|
| 教育訓練組 | 主持人／記錄共用名單與年度抽籤（52 週主持人＋12 個月全體會議記錄；事業部經理以上最多 1 次、其餘最多 2 次；可單格重抽）、值星表（另一份名單）、每年自動預排週一／五產壽險商品課（避開月例會、8–12 月區部聯合早會、國定假日）、可完全手動調整的月課表、講師時數紀錄與證明、全體會議記錄（匯出 Word） |
| 組織發展組／業務推展組 | 共用活動模組：活動企劃書（公司格式 Word）、報名收費、LINE 通知文字、請款單（公司格式 Word，金額自動轉國字大寫） |
| 業務推動組 | 三強三傑每月榮耀榜：產生含過場動畫的頒獎 PowerPoint、列印 A4 橫式獎狀 |
| 資訊推動組 | 粉專每週一、三、五發文主題規劃（撰稿發文由金牌粉專負責） |
| 總務財務組 | 公積金、營運基金收支帳，自動結餘、分類統計、月／年報表（Excel、列印） |

## 資料與隱私

- 所有資料只存在使用者自己裝置的瀏覽器（IndexedDB／localStorage）裡，不會上傳到任何伺服器；沒有帳號、沒有登入。
- 換裝置前請到「設定／備份」匯出 JSON 備份，再到新裝置匯入。
- 本站不含任何人的個人資料；內建的只有空白的「活動企劃書」與「請款單」格式。收款帳號只會存在使用者自己的裝置。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個 App（含 JSZip、PptxGenJS 函式庫與兩份空白 Word 範本） |
| `manifest.webmanifest` | 安裝設定 |
| `sw.js` | 離線快取 |
| `icons/` | App 圖示 |

非公勝公司官方發布之內部工具。
